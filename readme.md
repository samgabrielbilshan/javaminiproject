# Hospital Appointment Management System

## Overview
This is a desktop-based Hospital Appointment Management System developed in Java using Swing. It simplifies the process of scheduling, managing, and canceling patient appointments with doctors in a hospital environment. The system offers an intuitive graphical interface for selecting doctors, available time slots, and entering patient details efficiently, eliminating manual appointment errors.

## Features
- Select doctors from a predefined list.
- View and select available appointment slots.
- Enter patient name and age for booking.
- Real-time slot availability checking to avoid double bookings.
- Book, view, and cancel appointments.
- Appointment summaries and listings for easy management.

## System Requirements
- Java Development Kit (JDK) 8 or higher
- Any Java IDE (e.g., IntelliJ IDEA, Eclipse, NetBeans)
- Minimum hardware: 2GB RAM, 2.0 GHz processor

## Installation & Setup
1. Clone this repository: git clone https://github.com/samgabrielbilshan/javaminiproject
2. Open the project in a Java IDE.
3. Add the `HospitalAppointmentSystem.java` file to your source folder.
4. Compile and run the application through your IDE or use command line:
javac HospitalAppointmentSystem.java
java HospitalAppointmentSystem


## How to Use
1. Select a doctor and a preferred time slot.
2. Enter patient details (name and age).
3. Click "Check Availability" to verify if the slot is free.
4. If available, book the appointment by clicking "Book Appointment".
5. View all bookings and manage appointments via the summary panel.
6. Cancel selected bookings when necessary.
